# Daily Bot

**In development**

Daily Bot is a personal, self-hosted fork of [Rakazo](https://github.com/elie222/rakazo), an open-source AI assistant for running persistent bots. I’m building it for day-to-day use, with a focus on faster voice conversations, a better experience on iPhone and iPad, and more control over what my bots remember and do.

## What I’m working toward

| Area | Proposed changes |
| --- | --- |
| Voice calls | Faster replies in the existing call mode, followed by an optional realtime speech-to-speech mode. |
| iPhone and iPad | Dictation built into the message composer, better iPad layouts and keyboard support, and a Daily Bot build for TestFlight. |
| Memory and routines | Clearer memory updates, reviewable changes to bot instructions, and routine history with undo. |
| Reliability and controls | Clearer tool errors, more reliable connectors, usage limits, and event-driven Gmail routines. |
| Bot collaboration | Opt-in messaging between your own bots in different spaces within the same organization. |

These are proposed changes. The fork is at the planning stage and has no Daily Bot release yet. The first milestone is to sync with upstream Rakazo and set up a self-hosted development instance.
